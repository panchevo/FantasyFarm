# 🏰 Сказочная ферма

**Автор:** Панченко М. А.  
**Жанр:** фермерская стратегия с элементами славянской мифологии  
**Платформа:** браузер (HTML5)

---

## 📖 О чём игра

Вы — хозяин волшебной фермы, где вместо обычных животных обитают существа из славянских сказов: Жар-птицы, Огненные змеи, Волколаки, Ночницы, Василиски и Единороги. Они гуляют по полю, едят траву и оставляют после себя ценные ресурсы: перья, угольки, шкуры, серпы, камни и философские камни.

Ваша задача — выполнять задания уровней: собирать ресурсы, разводить существ, строить перерабатывающие здания и продавать всё это за алмазы 💎.

---

## 🎮 Управление

| Действие | Как выполнить |
|---|---|
| Посадить траву | Клик по полю (тратит 1 💧 воду) |
| Собрать ресурс | Клик по выпавшему ресурсу |
| Купить существо | Кнопка в шапке (справа) |
| Построить здание | Панель «🏗️ СТРОИТЕЛЬСТВО» → выбрать → клик по полю |
| Запустить переработку | Клик по построенному зданию |
| Продать все ресурсы | Кнопка «💰 Продать все» |
| Сбросить уровень | Кнопка «⟳ Сброс» |
| Проверить колодец | Клик по колодцу (показывает запас воды) |

## 🏗️ Здания и переработка

Здания покупаются за алмазы и строятся на поле. Клик по зданию запускает переработку: **1 ресурс → 1 ценный продукт**.

| Здание | Стоимость | Переработка | Время | Бонус при постройке |
|---|---|---|---|---|
| 🏗️ Гнездо | 8 💎 | перо → ✨ мана | 3 сек | +5 💎 |
| ⚒️ Кузня | 7 💎 | уголёк → 💎 алмаз | 2.5 сек | +4 💎 |
| 🐾 Волчья тропа | 10 💎 | шкура → 🧥 одежда | 3.5 сек | +6 💎 |
| 🏠 Лунный дом | 12 💎 | серп → 🧪 зелье | 4 сек | +7 💎 |
| 🏛️ Горгонариум | 14 💎 | камень → 🗿 статуя | 4.5 сек | +8 💎 |
| ⚗️ Филос. завод | 20 💎 | камень → ⚗️ эликсир | 6 сек | +15 💎 |

Переработанные продукты продаются дороже обычных ресурсов.

## ⏱️ Время и звёзды

На каждом уровне есть **лимит времени**. По истечении времени уровень проваливается.

Звёзды начисляются за скорость прохождения:

- ⭐⭐⭐ — уложились в первый порог
- ⭐⭐ — во второй порог
- ⭐ — в третий порог
- ☆ — не уложились

Чем быстрее выполнены все цели уровня, тем больше звёзд.

---

## 🎯 Цели уровней

Цели бывают пяти типов:

1. **Ресурс** — собрать N единиц ресурса (например, 5 🪶 перьев)
2. **Крафт** — произвести N переработанных продуктов (например, 3 ✨ маны)
3. **Существа** — иметь N живых существ определённого типа
4. **Здания** — построить N зданий определённого типа
5. **Очки** — набрать N очков (ресурсы + крафт + алмазы)

Все цели отображаются в шапке под названием уровня. Выполненные цели подсвечиваются зелёным.

## 💧 Вода и трава

- Вода восполняется в колодце автоматически (до 20 единиц).
- 1 клик по полю = 1 посаженная трава (тратит 1 💧).
- Трава нужна, чтобы кормить существ: они сами находят траву и едят её, восстанавливая HP.
- Без травы существа голодают и теряют здоровье, а при 0 HP — умирают.

---

## 💎 Экономика

- **Алмазы** — основная валюта. Тратятся на существ и здания.
- **Ресурсы** — продаются за алмазы.
- **Крафт** — продаётся дороже ресурсов.
- Кнопка «💰 Продать все» сбывает **всё** разом.

## 🏆 Советы

1. **Сначала трава, потом существа.** Без травы питомцы быстро погибнут.
2. **Не копите ресурсы.** Они исчезают через 15 секунд — собирайте сразу.
3. **Стройте здания заранее.** Переработка даёт больше алмазов, чем продажа сырья.
4. **Следите за таймером.** В шапке виден обратный отсчёт; при <20% времени он краснеет.
5. **Продавайте всё перед завершением уровня.** Очки за ресурсы и крафт идут в зачёт целей типа «score».
6. **Выбирайте героя под уровень.** Например, для уровня с Единорогами берите Василису.
