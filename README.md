# 🏰 Сказочная ферма — описание игры

**Сказочная ферма** — это пошаговая игра-менеджер с мифическими существами. Вам предстоит строить волшебные здания, разводить сказочных созданий и собирать ресурсы на протяжении **20 уровней** возрастающей сложности.

## 🎮 Основной геймплей

- **Сбор ресурсов** — кликайте по предметам, которые роняют существа: Жар-птица, Баранец, Волколак, Ночница, Василиск и Единорог
- **Покупка существ** за алмазы 💎 для расширения фермы
- **Посадка травы** 🌿 с помощью воды из колодца — она нужна для пропитания существ
- **Строительство зданий**, которые перерабатывают сырьё в готовые товары: ману, нить, одежду, зелья, статуи и эликсиры
- **Продажа ресурсов** ради алмазов и достижения целей уровня

## ✨ Ключевые особенности

| Особенность | Описание |
|---|---|
| **6 типов существ** | Жар-птица, Баранец, Волколак, Ночница, Василиск, Единорог — у каждого свой ресурс, здоровье и скорость голода |
| **6 типов зданий** | Гнездо, Паучий дом, Волчья тропа, Лунный дом, Горгонариум, Филос. завод |
| **20 уровней** | Разные цели: собрать ресурсы, создать предметы, построить здания или набрать очки |
| **Система звёзд** | От 1 до 3 звёзд ⭐ в зависимости от скорости прохождения |
| **Голод существ** | Кормите питомцев травой, иначе они погибнут |
| **Прогрессия** | Прохождение уровня открывает следующий |

## 🎨 Визуальный стиль

Оформление в духе **Civilization IV**: палитра пергамента, бронзы и золота, панели с золочёной окантовкой, скруглённые элементы интерфейса и детальная SVG-графика для каждого существа, здания и ресурса.

## 🎯 Цель игры

Пройти все **20 уровней**, выполняя уникальные задачи каждого этапа максимально эффективно и быстро.
